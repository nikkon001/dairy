# Дневник

Личный ежедневник в браузере. Всё хранится markdown-файлами в приватном репозитории на GitHub — читается и правится прямо там.

## Три раздела

Дневник разделён на вкладки — на компьютере они строкой под шапкой, на телефоне панелью внизу экрана.

| Вкладка | Что внутри |
|---|---|
| **Планер** | недельная сетка и режим дня, привычки, задачи, входящие |
| **Проекты** | проекты со сроками и этапами, желания |
| **Дневник** | запись, поиск, календарь, статистика, список записей |

Выбранная вкладка запоминается. Кнопка «Новая запись» сама переводит в «Дневник», «Новый проект» — в «Проекты», и так далее.

## Что внутри

**Каждый день**

- Цитата дня — меняется каждые сутки сама
- Планер: режим **День** и режим **Неделя**, часы с 06:00 до 23:00, события длиннее часа
- Три главных дела — звезда у самого важного
- Итог дня: что получилось и за что благодарна
- Перенос невыполненного — вчерашние дела одной кнопкой уезжают на сегодня
- Повторяющиеся дела — «каждый понедельник в 07:00 зал» появляется само

**Регулярно**

- Трекер привычек: месяц по дням, серии подряд идущих дней
- Задачи — общий список с прогрессом
- Входящие — быстрый буфер для мыслей, одной кнопкой уходят в задачи
- Проекты: сроки, этапы, линия прогресса, звезда при завершении
- Желания: пять вопросов, превращающих «хочу» в шаги

**Дневник**

- Записи с датой, тегами, настроением и фотографией
- Календарь месяца и статистика настроений
- Поиск по всему сразу — записи, задачи, этапы, планер, привычки

Планер и записи печатаются на бумагу кнопкой **Печать**.

## Как это устроено

Два репозитория:

| | Что внутри | Приватность |
|---|---|---|
| **Репозиторий с приложением** | только `index.html` | **публичный** |
| **Репозиторий с данными** | папка `entries/` и остальные файлы | **приватный** |

Приложение не хранит данные внутри себя — при открытии оно забирает их из GitHub по твоему токену. Поэтому публичная страничка безопасна: кто откроет ссылку без токена, увидит пустой дневник.

## Шаг 1. Репозиторий с приложением (публичный)

1. На GitHub → **New repository** → назови, например, `diary-app`, оставь **Public**
2. **Add file** → **Upload files** → перетащи `index.html`, `manifest.webmanifest`, `sw.js` и папку `icons/` → **Commit changes**
3. **Settings** → **Pages** → Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)** → **Save**
4. Через 1–2 минуты дневник откроется по адресу `https://ТВОЙ-НИК.github.io/diary-app/`

## Шаг 2. Репозиторий с данными (приватный)

**New repository** → назови `diary-entries`, выбери **Private**, поставь галочку **Add a README file**.

Папки создадутся сами при первой записи.

## Шаг 3. Токен

1. [github.com/settings/personal-access-tokens/new](https://github.com/settings/personal-access-tokens/new) — проверь, что вверху написано **Fine-grained token**
2. **Token name** — любое. **Expiration** — срок жизни
3. **Repository access** → **Only select repositories** → выбери `diary-entries`
4. **Permissions** → **Repository permissions** → длинный алфавитный список → найди **Contents** → **Read and write**
5. **Generate token** и скопируй сразу — GitHub показывает его один раз

> Не находится **Contents**? Значит ты либо на странице классических токенов, либо ещё не выбрала репозиторий на шаге 3 — список прав появляется только после этого.

## Шаг 4. Поставить на айфон

Дневник — PWA: он ставится на экран «Домой» и открывается как обычное приложение, без адресной строки.

1. Открой `https://ТВОЙ-НИК.github.io/diary-app/` **в Safari** (не в Chrome — на iOS установка работает только из Safari)
2. Кнопка **Поделиться** внизу экрана
3. Пролистай вниз → **На экран «Домой»**
4. **Добавить**

Появится иконка с красным корешком. Приложение запоминает вход, работает офлайн и обновляется само, когда есть интернет.

На Android и компьютере браузер предложит установку сам — в дневнике появится кнопка «Установить».

## Шаг 5. Подключить

⚙️ **Настройки** → владелец, репозиторий `diary-entries`, ветка `main`, папка `entries`, токен → **Подключить**.

Токен хранится только в этом браузере. Кнопки **Показать** и **Копировать** рядом с полем помогут перенести его на телефон.

## Файлы приложения

В публичном репозитории лежат:

```
index.html              само приложение
manifest.webmanifest    описание для установки на телефон
sw.js                   офлайн-режим
icons/                  иконки приложения
```

Офлайн-режим работает только по HTTPS, то есть на GitHub Pages. При открытии файла с компьютера напрямую он просто не включается — всё остальное работает как обычно.

## Файлы с данными

```
entries/2026-08-17-nazvanie.md   запись дня
media/2026-08-17-nazvanie.jpg    фото к записи
planner/2026-08-17.md            неделя планера (по дате понедельника)
tasks.md                         задачи
inbox.md                         входящие
habits.md                        привычки
repeat.md                        повторяющиеся дела
projects.md                      проекты
wishes.md                        желания
```

**Запись**

```markdown
---
title: Название записи
date: 2026-08-17
mood: joy
tags: мысли, книги
---

# Название записи

Текст записи…
```

Настроения: `joy` — радость, `calm` — спокойствие, `energy` — энергия, `cozy` — уют, `sad` — грусть.

**Неделя планера**

```markdown
# Планер · 17–23 августа 2026

## Пн · 2026-08-17

**09:00–11:00** Созвон с командой
**14:00** Зал

- [ ] ★ Оплатить счёт
- [x] Забрать посылку

**Итог:** много успела
**Благодарность:** за тёплый вечер
```

Диапазон времени означает событие на несколько часов, ★ — главное дело дня. Пустые дни в файл не попадают.

**Повторы**

```markdown
# Повторяющиеся дела

- Пн,Ср,Пт | 07:00 | Зал
- Ежедневно |  | Витамины
```

Со временем правило превращается в событие в сетке, без времени — в дело дня. Применяются один раз на неделю, когда ты её открываешь. Кнопка «Применить к этой неделе» в окне повторов добавит новые правила в уже открытую неделю.

**Привычки**

```markdown
# Привычки

## Вода

- 2026-08: 1 2 3 5 8
```

Числа — дни месяца, когда привычка закрыта.

Задачи, входящие, проекты и желания — обычные markdown-списки с чекбоксами, их можно отмечать прямо на GitHub.

## Синхронизация и сохранность

Списки хранятся каждый одним файлом целиком. Если один и тот же список изменили с двух устройств, дневник не перезапишет чужие правки молча — спросит, какую версию оставить.

Нет связи — запись остаётся на устройстве, а в шапке появляется «Не отправлено: N». Дневник досылает всё сам, когда интернет возвращается, и проверяет раз в минуту.

При загрузке скачиваются только изменившиеся записи, остальные берутся из памяти браузера.

Кнопка **Выйти** в настройках стирает токен и локальные копии — на случай чужого компьютера. Если что-то не уехало в GitHub, она предупредит и назовёт число.

**Скачать всё** выгружает записи, планер и все списки markdown-файлами.

## Мелочи

- На телефоне планер открывается в режиме дня, а блоки идут перед боковой колонкой
- Любой блок сворачивается кликом по заголовку — состояние запоминается
- `Ctrl/Cmd + S` — сохранить запись, `Esc` — закрыть окно
- `Enter` в списках создаёт следующий пункт, `Backspace` в пустом — убирает
- Иконка облака рядом с датой значит, что запись уже в GitHub
- Открыть `index.html` двойным щелчком на компьютере — работает так же
