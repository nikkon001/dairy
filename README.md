# Дневник

Личный ежедневник в браузере. Всё хранится markdown-файлами в приватном репозитории на GitHub — читается и правится прямо там.

## Разделы

Дневник разделён на вкладки — на компьютере они строкой под шапкой, на телефоне панелью внизу экрана.

| Вкладка | Что внутри |
|---|---|
| **Главная** | цели года, фокус месяца, событие недели, приоритеты дня, цитата, настроение, привычки, быстрые заметки |
| **Планер** | недельная сетка и режим дня, привычки, задачи, входящие |
| **Проекты** | roadmap, проекты со сроками и этапами |
| **Дом** | уборка по ритму, меню недели, рецепты, покупки, домашние дела, ремонт |
| **SWOT** | анализ по четырём квадрантам, список сохранённых |
| **Дневник** | запись, поиск, статистика, список записей |

Разделы можно выключать: ⚙️ Настройки → **Разделы**. Выключенный раздел исчезает из панели, его данные остаются в репозитории. Хотя бы один раздел должен остаться включённым.

Календарь и желания видны на всех вкладках: календарь сверху боковой колонки, желания внизу. На «Планере» клик по любому дню перекидывает планер на эту дату, а текущая неделя (или выбранный день) подсвечивается. На остальных вкладках клик по дню с записью открывает её. Маленькая сетка на дне означает, что в планере на него что-то запланировано.

Выбранная вкладка запоминается. Кнопка «Новая запись» сама переводит в «Дневник», «Новый проект» — в «Проекты», и так далее.

## Что внутри

**Каждый день**

- Цитата дня — меняется каждые сутки сама
- Планер: режим **День** и режим **Неделя**, часы с 06:00 до 23:00, события длиннее часа
- Три главных дела — звезда у самого важного
- Итог дня: что получилось и за что благодарна
- Перенос невыполненного — вчерашние дела одной кнопкой уезжают на сегодня
- Повторяющиеся дела — «каждый понедельник в 07:00 зал» появляется само

**Регулярно**

- Трекер привычек: месяц по дням, серии подряд идущих дней
- Задачи — общий список с прогрессом
- Входящие — быстрый буфер для мыслей, одной кнопкой уходят в задачи
- Проекты: сроки, этапы, линия прогресса, звезда при завершении
- Желания: пять вопросов, превращающих «хочу» в шаги

**Дневник**

- Записи с датой, тегами, настроением и фотографией
- Календарь месяца и статистика настроений
- Поиск по всему сразу — записи, задачи, этапы, планер, привычки

Планер и записи печатаются на бумагу кнопкой **Печать**.

## Как это устроено

Два репозитория:

| | Что внутри | Приватность |
|---|---|---|
| **Репозиторий с приложением** | только `index.html` | **публичный** |
| **Репозиторий с данными** | папка `entries/` и остальные файлы | **приватный** |

Приложение не хранит данные внутри себя — при открытии оно забирает их из GitHub по твоему токену. Поэтому публичная страничка безопасна: кто откроет ссылку без токена, увидит пустой дневник.

## Шаг 1. Репозиторий с приложением (публичный)

1. На GitHub → **New repository** → назови, например, `diary-app`, оставь **Public**
2. **Add file** → **Upload files** → перетащи `index.html`, `manifest.webmanifest`, `sw.js` и папку `icons/` → **Commit changes**
3. **Settings** → **Pages** → Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)** → **Save**
4. Через 1–2 минуты дневник откроется по адресу `https://ТВОЙ-НИК.github.io/diary-app/`

## Шаг 2. Репозиторий с данными (приватный)

**New repository** → назови `diary-entries`, выбери **Private**, поставь галочку **Add a README file**.

Папки создадутся сами при первой записи.

## Шаг 3. Токен

1. [github.com/settings/personal-access-tokens/new](https://github.com/settings/personal-access-tokens/new) — проверь, что вверху написано **Fine-grained token**
2. **Token name** — любое. **Expiration** — срок жизни
3. **Repository access** → **Only select repositories** → выбери `diary-entries`
4. **Permissions** → **Repository permissions** → длинный алфавитный список → найди **Contents** → **Read and write**
5. **Generate token** и скопируй сразу — GitHub показывает его один раз

> Не находится **Contents**? Значит ты либо на странице классических токенов, либо ещё не выбрала репозиторий на шаге 3 — список прав появляется только после этого.

## Шаг 4. Поставить на айфон

Дневник — PWA: он ставится на экран «Домой» и открывается как обычное приложение, без адресной строки.

1. Открой `https://ТВОЙ-НИК.github.io/diary-app/` **в Safari** (не в Chrome — на iOS установка работает только из Safari)
2. Кнопка **Поделиться** внизу экрана
3. Пролистай вниз → **На экран «Домой»**
4. **Добавить**

Появится иконка с красным корешком. Приложение запоминает вход, работает офлайн и обновляется само, когда есть интернет.

На Android и компьютере браузер предложит установку сам — в дневнике появится кнопка «Установить».

## Шаг 5. Подключить

⚙️ **Настройки** → владелец, репозиторий `diary-entries`, ветка `main`, папка `entries`, токен → **Подключить**.

Токен хранится только в этом браузере. Кнопки **Показать** и **Копировать** рядом с полем помогут перенести его на телефон.

## Файлы приложения

В публичном репозитории лежат:

```
index.html              само приложение
manifest.webmanifest    описание для установки на телефон
sw.js                   офлайн-режим
icons/                  иконки приложения
```

Офлайн-режим работает только по HTTPS, то есть на GitHub Pages. При открытии файла с компьютера напрямую он просто не включается — всё остальное работает как обычно.

## Файлы с данными

```
entries/2026-08-17-nazvanie.md   запись дня
media/2026-08-17-nazvanie.jpg    фото к записи
planner/2026-08-17.md            неделя планера (по дате понедельника)
tasks.md                         задачи
inbox.md                         входящие
habits.md                        привычки
repeat.md                        повторяющиеся дела
projects.md                      проекты
wishes.md                        желания
swot.md                          сохранённые SWOT-анализы
focus.md                         цели года, фокус месяца, событие недели
home.md                          уборка, покупки, дела, ремонт, меню, рецепты
```

**Запись**

```markdown
---
title: Название записи
date: 2026-08-17
mood: joy
tags: мысли, книги
---

# Название записи

Текст записи…
```

Настроения: `joy` — радость, `calm` — спокойствие, `energy` — энергия, `cozy` — уют, `sad` — грусть.

**Неделя планера**

```markdown
# Планер · 17–23 августа 2026

## Пн · 2026-08-17

**09:00–11:00** Созвон с командой
**14:00** Зал

- [ ] ★ Оплатить счёт
- [x] Забрать посылку

**Итог:** много успела
**Благодарность:** за тёплый вечер
```

Диапазон времени означает событие на несколько часов, ★ — главное дело дня. Пустые дни в файл не попадают.

**Повторы**

```markdown
# Повторяющиеся дела

- Пн,Ср,Пт | 07:00 | Зал
- Ежедневно |  | Витамины
```

Со временем правило превращается в событие в сетке, без времени — в дело дня. Применяются один раз на неделю, когда ты её открываешь. Кнопка «Применить к этой неделе» в окне повторов добавит новые правила в уже открытую неделю.

**Привычки**

```markdown
# Привычки

## Вода

- 2026-08: 1 2 3 5 8
```

Числа — дни месяца, когда привычка закрыта.

**Проекты**

```markdown
# Проекты

## Ремонт кухни

Сроки: 2026-08-01 — 2026-10-15

- [x] 2026-08-15 · Смета
- [ ] 2026-09-01 · Закупка
- [ ] Работы
```

Дата перед названием этапа необязательна: с ней этап встаёт вехой на roadmap, без неё остаётся обычной галочкой.

Входящие и желания — такие же markdown-списки с чекбоксами, их можно отмечать прямо на GitHub.

**Задачи**

```markdown
# Задачи

- [x] 2026-08-30 · Купить хлеб
- [ ] Позвонить маме
```

Дата у выполненной задачи — день, когда ты её закрыла. Через неделю такая задача убирается из списка сама, а до тех пор рядом с ней виден счётчик: «7 дней», «2 дня», «завтра». За два дня до удаления счётчик становится красным.

Снимешь галочку — дата стирается и отсчёт прекращается. Кнопка «Убрать сделанные» чистит список сразу, не дожидаясь недели. Задачи из старых файлов без даты не пропадут: отсчёт для них начнётся с первого открытия.

## SWOT

Четыре квадранта: сильные стороны, слабые стороны, возможности, угрозы. Плюсы помечены чёрным, минусы красным.

Пока анализ не сохранён, он остаётся **черновиком**: живёт только в этом браузере, в GitHub не уезжает и в списке не появляется. Черновик переживает перезагрузку страницы, так что можно вернуться к нему позже.

- **Сохранить** — черновик становится записью в списке и уезжает в `swot.md`
- **Не сохранять** — черновик стирается, ничего не остаётся
- **Удалить** — убирает уже сохранённый анализ навсегда

Клик по анализу в списке открывает его на правку; «Сохранить» обновит существующий, а не создаст копию.

```markdown
# SWOT

## 2026-08-28 · Смена работы

**Сильные стороны**

- опыт в продукте
- английский

**Слабые стороны**

- нет портфолио

**Возможности**

- рынок растёт

**Угрозы**

- конкуренция
```

Дата перед названием необязательна. Пустые квадранты в файл не пишутся.

## Главная страница

Дашборд дня. Всё на нём — живые данные из остальных разделов, а не отдельная копия.

- **Цели года** — слово года и список целей, хранятся в `focus.md`
- **Фокус** — одна главная вещь на месяц и главное событие недели
- **Приоритеты дня** — дела из планера, отмеченные звёздочкой; если звёздочек нет, показываются первые три
- **Настроение и привычки** — настроение дня пишется в файл недели строкой `**Настроение:** joy`, привычки отмечаются прямо тут
- **Быстрые заметки** — те же входящие, что в планере

```markdown
# Фокус

## 2026 · год

Слово года: Смелость

- [ ] Переехать
- [x] Выучить испанский

## 2026-08 · месяц

Фокус: Закончить ремонт

## 2026-08-24 · неделя

Событие: Отпуск на море
```

## Дом

Один файл `home.md` с шестью частями.

**Уборка** — не список, а ритм: у каждого дела своя периодичность и дата, когда ты его делала. Кнопка «Сделала» ставит сегодняшнее число, а рядом видно «через 5 дней» или красное «пора».

```markdown
## Уборка

- Пылесосить | 7 | 2026-08-28
- Помыть окна | 30 | 2026-08-01
```

Число после названия — раз во сколько дней, дальше дата последнего раза.

**Покупки, домашние дела, ремонт** — обычные чек-листы. Покупки вынесены в боковую колонку, чтобы были под рукой в магазине; у каждого списка есть «Убрать сделанные».

**Меню недели** — семь дней на завтрак, обед и ужин, с перелистыванием недель. На телефоне разворачивается в один столбец.

```markdown
## Меню 2026-08-24

- Пн | Овсянка | Суп | Рыба
- Ср | Сырники |  | Паста
```

**Рецепты** — название разворачивается по стрелке, внутри ингредиенты и способ приготовления. Кнопка **В покупки** переносит ингредиенты в список покупок, пропуская те, что уже там есть.

```markdown
## Рецепты

### Паста карбонара

Ингредиенты: спагетти, бекон, яйца, пармезан

Обжарить бекон.
Отварить пасту.
```

## Roadmap

Над карточками проектов — лента времени на 12 недель. Сверху шкала: месяцы крупно, под ними числа понедельников.

Первая строка — **вехи**: дедлайны всех проектов флажками с датой.

Дальше проекты идут группами. Чёрная плашка слева — название проекта и счётчик закрытых этапов, на шкале напротив неё тонкая линия от начала до дедлайна. Под группой — по строке на каждый этап с датой: слева дата, на шкале полоса с названием внутри.

Длина полосы считается цепочкой: этап начинается там, где закончился предыдущий, а первый — от начала проекта. То есть достаточно поставить этапу одну дату — его окончание.

Цвет полосы говорит о статусе:

- **чёрная заливка** — этап закрыт
- **красный контур** — идёт сейчас
- **красная заливка** — просрочен
- **серый контур** — ещё впереди

Вертикальная красная линия отмечает сегодня. У завершённого проекта плашка и линия становятся серыми, а в конце загорается звезда.

Стрелки листают ленту по четыре недели, «Сегодня» возвращает к текущей. Этапы без дат собраны отдельной строкой «без дат», а проекты без сроков перечислены под шкалой.

Этапы правятся прямо на ленте: название пишется внутри полосы, слева от неё галочка выполнения, поле даты и крестик удаления. Плюс на чёрной плашке проекта добавляет новый этап с сегодняшней датой. Всё то же самое остаётся доступным и в карточках ниже — это одни и те же данные.

## Синхронизация и сохранность

Списки хранятся каждый одним файлом целиком. Если один и тот же список изменили с двух устройств, дневник не перезапишет чужие правки молча — спросит, какую версию оставить.

Нет связи — запись остаётся на устройстве, а в шапке появляется «Не отправлено: N». Дневник досылает всё сам, когда интернет возвращается, и проверяет раз в минуту.

При загрузке скачиваются только изменившиеся записи, остальные берутся из памяти браузера.

Кнопка **Выйти** в настройках стирает токен и локальные копии — на случай чужого компьютера. Если что-то не уехало в GitHub, она предупредит и назовёт число.

**Скачать всё** выгружает записи, планер и все списки markdown-файлами.

## Мелочи

- На телефоне планер открывается в режиме дня, а блоки идут перед боковой колонкой
- Любой блок сворачивается кликом по заголовку — состояние запоминается
- `Ctrl/Cmd + S` — сохранить запись, `Esc` — закрыть окно
- `Enter` в списках создаёт следующий пункт, `Backspace` в пустом — убирает
- Иконка облака рядом с датой значит, что запись уже в GitHub
- Открыть `index.html` двойным щелчком на компьютере — работает так же
