# 🌸 Мой дневник

Личный дневник в браузере. Записи сохраняются отдельными `.md` файлами прямо в папку `entries/` этого репозитория.

## Что умеет

- Заметки с заголовком, датой, тегами и настроением дня
- Поиск по тексту и фильтр по тегам
- Календарь месяца — дни с записями подсвечены цветом настроения
- Сохранение в GitHub одним нажатием (плюс копия в браузере, работает офлайн)
- Кнопка «Скачать все записи» на случай, если захочется забрать всё с собой

## Как перенести на GitHub

1. Создай новый репозиторий на GitHub (можно приватный — так надёжнее, дневник всё-таки).
2. Загрузи туда `index.html`, `README.md` и папку `entries/`.
3. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)` → Save.
4. Через пару минут дневник будет доступен по адресу `https://ТВОЙ-НИК.github.io/НАЗВАНИЕ-РЕПО/`.

## Как включить сохранение записей в репозиторий

1. Открой [github.com/settings/personal-access-tokens/new](https://github.com/settings/personal-access-tokens/new)
2. **Repository access** → Only select repositories → выбери репозиторий дневника
3. **Permissions** → Repository permissions → **Contents: Read and write**
4. Сгенерируй токен и скопируй его (он показывается один раз)
5. В дневнике нажми ⚙️ **Настройки**, заполни поля и вставь токен

Токен хранится только в твоём браузере (localStorage) и отправляется напрямую в GitHub — больше никуда.

## Формат записи

Каждая запись — файл `entries/2026-08-16-nazvanie.md`:

```markdown
---
title: Название записи
date: 2026-08-16
mood: joy
tags: мысли, книги
---

# Название записи

Текст записи…
```

Файлы читаются прямо на GitHub, так что дневник можно листать даже без приложения.

## Локально

Просто открой `index.html` двойным щелчком — всё работает и без GitHub Pages.

## Горячие клавиши

- `Ctrl/Cmd + S` — сохранить запись
- `Esc` — закрыть настройки
